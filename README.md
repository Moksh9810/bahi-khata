# 💰 MYWEALTH - Investment Portfolio Tracker

Track, analyze, and grow your wealth across multiple asset classes.

## 🎯 What is MYWEALTH?

MYWEALTH is a comprehensive investment portfolio management platform that helps you:

- **Track** 8 different asset types (Stocks, Mutual Funds, Bonds, Loans, Crypto, Gold, Properties, FDs)
- **Analyze** your portfolio performance with charts and advanced analytics
- **Optimize** your investment strategy with AI-powered recommendations
- **Secure** your financial data with industry-standard encryption

## 📊 Key Features

### 📱 Portfolio Management
- Track 8 asset types with custom holdings
- Real-time P&L calculations
- Asset allocation analysis
- Category-wise breakdown

### 📈 Analytics & Insights
- Portfolio growth charts
- Asset allocation pie charts
- Performance comparison bar charts
- Sharpe ratio calculations
- Volatility analysis

### 🎨 Beautiful UI
- Dark mode with glass morphism design
- Responsive design (mobile, tablet, desktop)
- Stitch design system
- Smooth animations and transitions

### 🔒 Security
- Supabase authentication
- Row-level security (RLS)
- End-to-end encrypted data
- Regular security audits

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ (LTS recommended)
- npm or yarn
- Modern browser (Chrome, Firefox, Safari, Edge)

### Installation

```bash
# Clone the repository
git clone https://github.com/Moksh9810/bahi-khata.git
cd bahi-khata

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser at http://localhost:5173
```

### Build for Production
```bash
npm run build
npm run preview
```

## 📖 Usage Example

### Sign Up
1. Open MYWEALTH app
2. Click "Sign Up"
3. Enter email and password (min 6 characters)
4. Click "Sign Up"
5. Account created and logged in

### Add Holdings
1. Click on asset type tab (Stocks, MF, etc.)
2. Click "Add" button
3. Fill in the form with holdings details
4. Click "Save"
5. Holding appears in portfolio

### View Analytics
1. Click "Analytics" tab
2. Select time period (1M, 3M, 6M, 1Y, All)
3. View charts and metrics
4. Get recommendations
